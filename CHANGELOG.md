# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-04

### Added
- Flutter app with MVVM + BLoC architecture and Dio networking.
- Login / sign-up and six-step onboarding.
- Swipe deck with like, pass, super like, rewind and discovery filters.
- Match screen, Likes You, matches list with 24h expiry, chat with icebreakers.
- "Us" relationship space: partner requests, days together, anniversary, mood check-ins, date plans, memories.
- Profile view, edit and preview.
- In-memory mock API so the app runs without a backend.
- Backend API contract (`docs/API_CONTRACT.md`).
- Bloc unit tests and GitHub Actions CI.
