# Security Policy

A dating app handles personal data, so security reports are taken seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report it privately through
[GitHub Security Advisories](https://github.com/Abdulsathar27/amora-dating-app/security/advisories/new).

Include the steps to reproduce, the affected version or commit, and the impact.
You will get a reply within 7 days.

## Supported versions

| Version | Supported |
|---|---|
| `main` | ✅ |
| older | ❌ |
